# Evidence Atlas source catalog crosswalk

**Status: proposed metadata-only inventory; not an approved evidence import**

## Method and limits

This crosswalk classifies only titles, authors/organizations, document types, registry identifiers, dates, URLs, and notes already present in `data/sources.csv` and `data/trials.csv` at the Phase 2 snapshot. It does not retrieve or re-review source documents, extract outcomes, establish clinical validity, change a registry status, or approve any record for Atlas use. IDs are copied from the repository catalogs. No ID is invented. A registry record and a publication about the same study are separate catalog records, not independent cohorts.

Candidate labels refer to `EVIDENCE-ATLAS-TAXONOMY.md`: intent IDs `TI-*`, mechanism IDs `TM-*`; `none/unknown` means the catalog metadata does not support a therapeutic classification. RQ references use `RQ-*` from `EVIDENCE-ATLAS-RESEARCH-QUESTIONS.md`. Confidence describes confidence in this **metadata-level classification only**, not evidence strength or clinical conclusions. `High` means the catalog metadata names the class directly; `Moderate` means an intended mechanism is reasonably explicit but incompletely specified; `Low/unknown` means the candidate cannot be resolved from catalog metadata. Every row still requires human adjudication before future evidence use.
